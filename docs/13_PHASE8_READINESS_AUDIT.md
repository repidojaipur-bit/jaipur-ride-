## 4. Phase 8 Hardening Changes Applied During Audit

- **`app/src/main/AndroidManifest.xml`:** Changed `android:allowBackup="false"` and added `android:usesCleartextTraffic="false"` to protect local DataStore files and block cleartext traffic on API 24–27.
- **`app/proguard-rules.pro` & `app/build.gradle.kts`:** Enabled R8 (`isMinifyEnabled = true`, `isShrinkResources = true`) on `release`, wired external keystore property support (`DRIVE_PARTNER_KEYSTORE_*`), and added Kotlinx Serialization / Retrofit 2 / OkHttp keep rules.
- **`app/src/main/java/com/drivepartner/app/core/network/SafeLoggingInterceptor.kt`:** Extended `SafeLogSanitizer.redactSensitiveFields` to also redact numeric JSON values and URL query parameters (`token=`, `idToken=`, `otp=`, `phone=`).
- **`app/src/main/java/com/drivepartner/app/core/network/RetrofitClientFactory.kt` & `DispatchRealtimeBoundary.kt`:** Enforced strict `https://` (`API_BASE_URL`) and `wss://` (`REALTIME_WS_URL`) validation in `LIVE` mode and replaced `println` with debug-guarded `Log.d`.
- **`.github/workflows/android-ci.yml`:** Added `gradle assembleLiveRelease` check to CI so R8 release compilation is verified alongside debug builds, lint, and JVM unit tests.
- **Test Compile Fixes (`Phase7ModelsAndDeepLinkTest.kt`, `RetentionSafetyCoordinatorTest.kt`, `Phase7ViewModelsTest.kt`, `Phase7ScreensTest.kt`, `EnvironmentIsolationTest.kt`, `SafeLogSanitizerTest.kt`, `RealtimeBoundaryAndDeduplicationTest.kt`):** Fixed 8 symbol/constructor mismatches discovered by cross-file static verification and added assertions for cleartext HTTPS/WS rejection and query-param redaction.
