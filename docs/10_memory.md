## 3. Product terminology
- **Applicant:** registered but not live-eligible.
- **Driver/Partner:** person performing the offered work.
- **Offer:** expiring assignment invitation, not yet accepted work.
- **Order:** underlying work request.
- **Trip/Job:** execution lifecycle associated with an accepted order; Delivery may use generic job naming in API.
- **Estimated earnings:** pre-completion estimate, not guaranteed final money.
- **Earning statement:** finalized calculation for a work source.
- **Ledger:** immutable financial postings.
- **Available wallet balance:** amount eligible for payout under backend rules.
- **Payout:** request/transfer to an approved payout account.
- **Auto Boost:** backend-configured preference/eligibility feature; never auto-accept.
- **Priority order:** backend-defined campaign or dispatch label; not self-assigned.
